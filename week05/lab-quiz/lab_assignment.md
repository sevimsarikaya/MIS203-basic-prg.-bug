# Week 5 Lab: Reusable Shipping Quote

## Task

Create `lab05_shipping_quote.py`. Implement separate functions for subtotal, discount rate, shipping fee and final total. Call the functions for at least two sample orders.

## Acceptance Checks

1. Each function has a clear parameter and returns a value.
2. The same calculation code is not copied for the second order.
3. Include at least three `assert` checks, including a threshold boundary.
4. Explain the difference between `print` and `return`.


## GitHub Submission

1. Create `week05/lab-quiz/` in your own course repository and save `lab05_shipping_quote.py` there. Keep weekly homework in `week05/` outside this folder.
2. Add a short README note with one test you ran and one thing you changed after testing.
3. Commit with a specific message, such as `week05: complete reusable shipping quote`.
4. Show the running program and your commit history to the instructor.
